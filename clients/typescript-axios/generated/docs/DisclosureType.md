# DisclosureType

* `PrescribingInformation` (value: `'PRESCRIBING_INFORMATION'`)

* `PrescribingInformationBoxWarning` (value: `'PRESCRIBING_INFORMATION_BOX_WARNING'`)

* `ImportantSafetyInfo` (value: `'IMPORTANT_SAFETY_INFO'`)

* `MedGuide` (value: `'MED_GUIDE'`)

* `PatientInformation` (value: `'PATIENT_INFORMATION'`)

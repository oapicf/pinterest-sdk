This is the API

advertiserDefinedEvents/create

Map advertiser defined events to standard events for the given ad account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/advertiser_defined_events

HTTP Method

POST

Response Type

advertiser_defined_events_create_200_response

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Body: AdvertiserDefinedEventsCreateRequest AdvertiserDefinedEventsCreateRequest(AdvertiserDefinedEventsCreateRequest)

advertiserDefinedEvents/delete

Untrack advertiser defined events for the given ad account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/advertiser_defined_events

HTTP Method

DELETE

Response Type

advertiser_defined_events_create_200_response

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Query: event_names List(String)

    List of event names to delete

advertiserDefinedEvents/get

Get advertiser defined events for the given ad account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/advertiser_defined_events

HTTP Method

GET

Response Type

advertiser_defined_events_get_200_response

Parameters

    Unique identifier of an ad account.

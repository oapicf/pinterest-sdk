This is the API

adsCredit/redeem

Redeem ads credit on behalf of the ad account id and apply it towards billing. **This endpoint might not be available to all apps. [Learn more](/docs/getting-started/using-beta-and-restricted-features/).**

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/ads_credit/redeem

HTTP Method

POST

Response Type

AdsCreditRedeem

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Body: AdsCreditRedeemCreate AdsCreditRedeemCreate(AdsCreditRedeemCreate)

billingInvoices/get

Get billing invoices in the advertiser account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/billing_invoices

HTTP Method

GET

Response Type

billing_invoices_get_200_response

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Query: bookmark String

    Cursor used to fetch the next page of items

  • Query: page_size Integer

    Maximum number of items to include in a single page. See documentation on [Pagination](/docs/reference/pagination/) for more information.

  • Query: order PinterestLibPaginationOrder

    The order in which to sort the items returned: \"ASCENDING\" or \"DESCENDING\" by ID. Note that higher-value IDs are associated with more-recently added items.

  • Query: sort BillingInvoiceSortField

    Field of which to sort billing invoices

  • Query: status BillingInvoiceStatus

    Status of billing invoices to filter by

  • Query: document_type BillingInvoiceDocumentType

    Document type of billing invoices to filter by

  • Query: start_due_date date

    Starting point for due dates when searching for invoices. Format: YYYY-MM-DD

  • Query: end_due_date date

    Ending point for due dates when searching for invoices. Format: YYYY-MM-DD

ssioAccounts/get

Get Salesforce account details including bill-to information to be used in insertion orders process for `ad_account_id`. - The token's `user_account` must either be the owner of the specified ad account, or have one of the necessary roles granted via [Business Access](https://help.pinterest.com/en/business/article/share-and-manage-access-to-your-ad-accounts): Admin, Finance, Campaign.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/ssio/accounts

HTTP Method

GET

Response Type

SSIOAccount

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

This is the API

schedules/create

Batch create schedules

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/schedules

HTTP Method

POST

Response Type

List

Parameters

  • Path: ad_account_id String

  • Body: ScheduleCreate List(ScheduleCreate)

schedules/list

Get schedules for a specific advertiser

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/schedules

HTTP Method

GET

Response Type

schedules_list_200_response

Parameters

  • Path: ad_account_id String

  • Query: entity_ids List(String)

    List of Entity IDs, must be associated with the Ad Accound ID provided in the path.

  • Query: bookmark String

    Cursor used to fetch the next page of items

  • Query: page_size Integer

    Maximum number of items to include in a single page. See documentation on [Pagination](/docs/reference/pagination/) for more information.

  • Query: order PinterestLibPaginationOrder

    The order in which to sort the items returned: \"ASCENDING\" or \"DESCENDING\" by ID. Note that higher-value IDs are associated with more-recently added items.

  • Query: schedule_statuses List(ScheduleStatus)

    Filter schedules by status (one or more)

  • Query: schedule_type ScheduleType

    Filter schedules by a type

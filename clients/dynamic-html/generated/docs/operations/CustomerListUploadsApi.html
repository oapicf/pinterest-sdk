This is the API

customerListUploads/create

Create a customer list upload request for multipart S3 upload. Note: Each part must be at least 5mb; however the last part can be any size greater than 0. Clients with smaller files can request a single part count. This minimal part size restriction is defined by the AWS S3 API. **Please review the [update customer list endpoint](/docs/api/v5/customer_lists-update/) documentation for additional information.**

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/customer_lists/{customer_list_id}/uploads

HTTP Method

POST

Response Type

CustomerListUploadCreateResponse

Parameters

  • Path: ad_account_id String

  • Path: customer_list_id String

    Customer list ID.

  • Body: CustomerListUploadCreateRequest CustomerListUploadCreateRequest(CustomerListUploadCreateRequest)

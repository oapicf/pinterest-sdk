This is the API

audiences/create

Create a new audience for the ad account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/audiences

HTTP Method

POST

Response Type

AdAccountsAudience

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Body: AdAccountsAudienceCreate AdAccountsAudienceCreate(AdAccountsAudienceCreate)

audiences/get

Get a specific audience given the audience ID.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/audiences/{audience_id}

HTTP Method

GET

Response Type

AdAccountsAudience

Parameters

  • Path: audience_id String

    Audience ID.

  • Path: ad_account_id String

    Unique identifier of an ad account.

audiences/list

Get list of audiences for the ad account.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/audiences

HTTP Method

GET

Response Type

audiences_list_200_response

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Query: bookmark String

    Cursor used to fetch the next page of items

  • Query: page_size Integer

    Maximum number of items to include in a single page. See documentation on [Pagination](/docs/reference/pagination/) for more information.

  • Query: order PinterestLibPaginationOrder

    The order in which to sort the items returned: \"ASCENDING\" or \"DESCENDING\" by ID. Note that higher-value IDs are associated with more-recently added items.

  • Query: ownership_type AudienceOwnershipType

  • Query: exclude_nca Boolean

    When true, excludes audiences derived from new customer acquisition (expanded matching) customer lists from the result. Defaults to false (include all).

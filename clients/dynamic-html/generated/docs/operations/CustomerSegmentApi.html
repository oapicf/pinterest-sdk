This is the API

customerSegment/create

Customer segments allow advertisers to define existing customers for Pinterest Performance+ campaigns. Customer segments are made up of audience lists.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/customer_segments

HTTP Method

POST

Response Type

CustomerSegment

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Body: CustomerSegmentCreate CustomerSegmentCreate(CustomerSegmentCreate)

customerSegment/list

Get a list of the customer segments in the specified `ad_account_id`.

URL

https://api.pinterest.com/v5/ad_accounts/{ad_account_id}/customer_segments

HTTP Method

GET

Response Type

customer_segment_list_200_response

Parameters

  • Path: ad_account_id String

    Unique identifier of an ad account.

  • Query: bookmark String

    Cursor used to fetch the next page of items

  • Query: page_size Integer

    Maximum number of items to include in a single page. See documentation on [Pagination](/docs/reference/pagination/) for more information.

  • Query: order PinterestLibPaginationOrder

    The order in which to sort the items returned: \"ASCENDING\" or \"DESCENDING\" by ID. Note that higher-value IDs are associated with more-recently added items.

  • Query: include_sizing Boolean

    Include audience sizing in result or not

  • Query: search_query String

    Search query. Can contain pin description keywords or comma-separated pin IDs.
